# One useful improvement at a time

I want to keep this project moving without turning GitHub into another chore. A short weekly session should leave something useful behind.

## A simple routine

1. Pick one small task.
2. Write down what needs to change and why.
3. Make the change and check it.
4. Commit it with a message that explains what changed.
5. Leave a short note about what I learned or what comes next.

There is no need to force a code change every week. A clear design decision, a testing note, or a useful diagram can be just as valuable.

## Before adding a project

Can I explain the problem, my role, and the decisions I made? Can I show the work without exposing customer information? Is its status clear? If it is still a concept, I will say so.
